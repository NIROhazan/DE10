### Q01 - תפסן קביעה-איפוס מהשקופיות

- **מתגים ונורות:** `S = SW9     R = SW8     Q = LEDR1     Q' = LEDR0` ; `case 1 = HEX3 HEX2     case 2 = HEX1 HEX0     answer: SW1 SW0`
- **שלבים:** 2

**שלב 1**

- נתון תפסן הקביעה-איפוס מהשקופיות, משני שערים:
- `N1:  Q = NOR(R, Q')     N2:  Q' = NOR(S, Q)`
- שימו את מתגי הכניסה כמו במצב 1 שבתצוגת ההקס שעל הלוח:
- `S = HEX3     R = HEX2`
- העתיקו כל נורה למתג שמתחתיה: נורה דולקת = מתג למעלה.
- `LEDR1 -> SW1     LEDR0 -> SW0`

**שלב 2**

- עכשיו, בלי לאפס את הלוח, שימו את מתגי הכניסה כמו במצב 2 שבתצוגת ההקס שעל הלוח:
- `S = HEX1     R = HEX0`
- העתיקו כל נורה למתג שמתחתיה: נורה דולקת = מתג למעלה.
- `LEDR1 -> SW1     LEDR0 -> SW0`
- רמז: תפסן זוכר. הנורות תלויות גם במצב הקודם, לא רק במתגים של עכשיו.

### Q07 - תפסן SR - מה קובע, מה מאפס?

- **מתגים ונורות:** `two switches = SW9 SW8     Q = LEDR1     Q' = LEDR0     answer: SW1 SW0`
- **שלבים:** 4

**שלב 1**

- נתון תפסן קביעה-איפוס על שני מתגים. לא ידוע איזה מתג קובע ואיזה מאפס.
- בדקו באיזה מצב של שני המתגים התפסן קובע:
- `Q = LEDR1 = 1     Q' = LEDR0 = 0`
- העתיקו את המצב הזה למתגי התשובה:
- `SW9 -> SW1     SW8 -> SW0`
- רמז: נסו את כל 4 המצבים:
- `SW9 SW8 = 00     01     10     11`

**שלב 2**

- בדקו באיזה מצב התפסן מאפס:
- `Q = LEDR1 = 0     Q' = LEDR0 = 1`
- העתיקו את המצב הזה למתגי התשובה:
- `SW9 -> SW1     SW8 -> SW0`

**שלב 3**

- בדקו באיזה מצב התפסן זוכר: כשמגיעים אליו, הנורות לא משתנות.
- העתיקו את המצב הזה למתגי התשובה:
- `SW9 -> SW1     SW8 -> SW0`

**שלב 4**

- יש שני סוגים של תפסן קביעה-איפוס:
- `NOR latch:    sets / resets when the input is 1`
- `NAND latch:   sets / resets when the input is 0`
- בדקו מאיזה סוג התפסן שבלוח, והרימו לפי הסוג:
- `NOR -> all 0     NAND -> SW0`
- רמז: היעזרו במצב שבו התפסן זוכר, מהשלב הקודם.

### Q50 - איזה מודול מהשקופיות?

- **מתגים ונורות:** `reset = SW9     d = SW8     en (or the latch clk) = SW7     q before = SW6` ; `LEDR1 = q now     LEDR0 = q after the next clock edge` ; `answer: SW3..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח אחד מארבעת המודולים מהשקופיות:
- `flop:     always_ff @(posedge clk) q <= d;`
- `flopr:    always_ff @(posedge clk, posedge reset) if (reset) q <= 0; else q <= d;`
- `flopren:  always_ff @(posedge clk, posedge reset) if (reset) q <= 0; else if (en) q <= d;`
- `latch:    always_latch if (clk) q <= d;     (clk = SW7, both LEDs show the latch)`
- אין שעון: הערך הקודם על מתג, ושתי נורות מראות את הערך עכשיו ואחרי עליית השעון הבאה.
- הורידו את האיפוס והרימו את מתג האפשור. בלי לגעת בערך הקודם, שנו את הנתון ובדקו את הנורה של עכשיו:
- `LEDR1`
- היא הולכת אחרי הנתון - הרימו:
- `SW0`
- היא לא משתנה - השאירו את כל המתגים למטה.

**שלב 2**

- עכשיו זהו את המודול:
- `flop:     always_ff @(posedge clk) q <= d;`
- `flopr:    always_ff @(posedge clk, posedge reset) if (reset) q <= 0; else q <= d;`
- `flopren:  always_ff @(posedge clk, posedge reset) if (reset) q <= 0; else if (en) q <= d;`
- `latch:    always_latch if (clk) q <= d;     (clk = SW7, both LEDs show the latch)`
- הרימו את המתגים של המודול שמצאתם (0 = למטה, 1 = למעלה):
- `SW1 SW0`
- `flop -> 00     flopr -> 01     flopren -> 10     latch -> 11`
- אם יוצא שכל המתגים למטה - גם זו תשובה, ובודקים אותה כרגיל.
- רמז: בדקו מה עושה האיפוס, ומה עושה מתג האפשור כשהאיפוס למטה.
