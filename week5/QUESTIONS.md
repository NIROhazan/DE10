### Q07 - תפסן (לאטש) SR - מה קובע, מה מאפס?

- **מתגים ונורות:** `two switches = SW9 SW8     Q = LEDR1     Q' = LEDR0     answer: SW1 SW0`
- **שלבים:** 4

**שלב 1**

- בדקו באיזה מצב של שני המתגים התפסן (לאטש) קובע:
- `Q = LEDR1 = 1     Q' = LEDR0 = 0`
- העתיקו את המצב הזה למתגי התשובה:
- `SW9 -> SW1     SW8 -> SW0`
- רמז: נסו את כל 4 המצבים:
- `SW9 SW8 = 00     01     10     11`

**שלב 2**

- בדקו באיזה מצב התפסן (לאטש) מאפס:
- `Q = LEDR1 = 0     Q' = LEDR0 = 1`
- העתיקו את המצב הזה למתגי התשובה:
- `SW9 -> SW1     SW8 -> SW0`

**שלב 3**

**שלב 4**

- יש שני סוגים של תפסן (לאטש) קביעה-איפוס:
- `NOR latch:    sets / resets when the input is 1`
- `NAND latch:   sets / resets when the input is 0`
- בדקו מאיזה סוג התפסן (לאטש) שבלוח, והרימו לפי הסוג:
