# תרגיל 14 - בינארי, עשרוני והקסה

הרצאה 2: מערכות ספירה, המרות, ביטים / ניבלים / בתים, חזקות של 2.

## הלוח

- `SW9..SW0` = המספר N (10 ביטים), מוצג על `LEDR9..LEDR0` ו**בהקסה** על `HEX2 HEX1 HEX0` (לא בעשרוני!).
- לוחצים ומחזיקים `KEY3`: התצוגות הופכות ל-`-`, ו-`LEDG7..LEDG0` מראים **בית סודי** של הפאזל `SW5..SW0`.

## השאלות

| קובץ | מה שואלים |
|---|---|
| `Q1_DEC.bat` | עשרוני -> מתגים (בינארי) |
| `Q2_HEX.bat` | הקסה -> עשרוני |
| `Q3_BIN.bat` | מתגים -> הקסה ועשרוני |
| `Q4_SECRET.bat` | קוראים את הבית הסודי מהלדים - **חייבים את הלוח** |
| `Q5_BITS.bat` | כמה ביטים / ספרות הקסה |
| `Q6_POWERS.bat` | הערכת חזקה של 2 (K / M / G) |

## איך עובדים

- לכל שאלה קובץ BAT משלה (`Q1_....bat`). דאבל-קליק: הלוח נצרב, השאלה מופיעה בחלון, מקלידים את התשובה שם. לא עורכים שום קובץ.
- **המספרים אישיים** - נבנים ממספר הסטודנט (נשמר ב-`student.txt` בתיקיית הקורס, אותו מספר לכל התרגילים).
- **תשובה שגויה = מספרים חדשים.** אין טעם לנחש - פותרים שוב מההתחלה.
- תשובה נכונה נותנת **קוד** בקובץ `moodle.txt` - אותו מגישים במודל. כל ניסיון נרשם ב-`results.txt`.
- `S` = לדלג על השאלה, `Q` = לעצור.
- SW0 הוא המתג הימני ביותר, HEX0 התצוגה הימנית ביותר.
