# תרגיל 18 - שערים מסתוריים

הרצאה 2: NOT, BUF, AND, OR, NAND, NOR, XOR, XNOR ושערים עם 3 כניסות.

## הלוח

- `A = SW0`, `B = SW1`, `C = SW2`. מספר הפאזל = `SW9..SW6` בבינארי (מוצג על HEX0).
- `LEDG7..LEDG0` = שמונה שערים נסתרים של הפאזל. עוברים על כל השורות של A B C, כותבים טבלת אמת, ומזהים את השער.
- השמות: `BUF NOT AND OR NAND NOR XOR XNOR` (כניסות A B; BUF ו-NOT רק A), `AND3 OR3 NAND3 NOR3 XOR3 XNOR3`.
- **כל השאלות כאן דורשות את הלוח** - התשובות לא כתובות באף קובץ.

## השאלות

| קובץ | מה שואלים |
|---|---|
| `Q1_TWO.bat` | שני שערים של 2 כניסות |
| `Q2_THREE.bat` | שער של 3 כניסות |
| `Q3_PAIR.bat` | שני לדים שתמיד הפוכים |
| `Q4_FIND.bat` | מחפשים את הפאזל הנכון מבין 0..15 |
| `Q5_ALL.bat` | כל שמונת השערים |

## איך עובדים

- לכל שאלה קובץ BAT משלה (`Q1_....bat`). דאבל-קליק: הלוח נצרב, השאלה מופיעה בחלון, מקלידים את התשובה שם. לא עורכים שום קובץ.
- **המספרים אישיים** - נבנים ממספר הסטודנט (נשמר ב-`student.txt` בתיקיית הקורס, אותו מספר לכל התרגילים).
- **תשובה שגויה = מספרים חדשים.** אין טעם לנחש - פותרים שוב מההתחלה.
- תשובה נכונה נותנת **קוד** בקובץ `moodle.txt` - אותו מגישים במודל. כל ניסיון נרשם ב-`results.txt`.
- `S` = לדלג על השאלה, `Q` = לעצור.
- SW0 הוא המתג הימני ביותר, HEX0 התצוגה הימנית ביותר.
