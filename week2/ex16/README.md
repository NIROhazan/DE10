# תרגיל 16 - מספרים מסומנים

הרצאה 2: Sign/Magnitude, Two's Complement, חיסור, גלישה, טווחים.

## הלוח

- מחבר של 4 ביטים: `X = SW3..SW0` (HEX0), `Y = SW7..SW4` (HEX1), `S = X + Y` על `HEX3` ו-`LEDG3..LEDG0`.
- `LEDG6` = נשא יוצא, `LEDG7` = **גלישה מסומנת** (Two's Complement). ה-HEX מראים תבניות ביטים, לא ערך עם סימן.

## השאלות

| קובץ | מה שואלים |
|---|---|
| `Q1_TWOS.bat` | מספר שלילי ב-Two's Complement |
| `Q2_SIGNMAG.bat` | מספר שלילי ב-Sign/Magnitude |
| `Q3_READ.bat` | 8 ביטים בשלוש קריאות |
| `Q4_SUB.bat` | חיסור = חיבור של השלילי |
| `Q5_OVERFLOW.bat` | גבולות הגלישה המסומנת |
| `Q6_RANGE.bat` | טווחים של N ביטים |

## איך עובדים

- לכל שאלה קובץ BAT משלה (`Q1_....bat`). דאבל-קליק: הלוח נצרב, השאלה מופיעה בחלון, מקלידים את התשובה שם. לא עורכים שום קובץ.
- **המספרים אישיים** - נבנים ממספר הסטודנט (נשמר ב-`student.txt` בתיקיית הקורס, אותו מספר לכל התרגילים).
- **תשובה שגויה = מספרים חדשים.** אין טעם לנחש - פותרים שוב מההתחלה.
- תשובה נכונה נותנת **קוד** בקובץ `moodle.txt` - אותו מגישים במודל. כל ניסיון נרשם ב-`results.txt`.
- `S` = לדלג על השאלה, `Q` = לעצור.
- SW0 הוא המתג הימני ביותר, HEX0 התצוגה הימנית ביותר.
