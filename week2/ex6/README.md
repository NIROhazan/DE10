# תרגיל 6 - שערי CMOS

הרצאה 2: טרנזיסטורי nMOS / pMOS, רשת Pull-Up ו-Pull-Down, NAND, NOR3, AND2.

## הלוח

- `A = SW0`, `B = SW1`, `C = SW2`. מספר הפאזל = `SW9..SW6` (מוצג על HEX0). המוצא Y של שער CMOS נסתר: `LEDG0` ו-`HEX3`.
- השערים: `NOT NAND2 NOR2 NAND3 NOR3 AND2 OR2` (כל שער יכול להשתמש בכל אחת מהכניסות A B C).
- לשאלת המומחים: `AOI21: Y = NOT(x*y + z)`, `OAI21: Y = NOT((x + y)*z)` - z היא הכניסה ה"בודדת".
- מזהים את השער מטבלת האמת, ואז עונים על הטרנזיסטורים שלו (טורי / מקבילי, כמה טרנזיסטורים). **דורש את הלוח.**

## השאלות

| קובץ | מה שואלים |

| `Q1_NAME.bat` | איזה שער |
| `Q2_COUNT.bat` | כמה טרנזיסטורים |

## איך עובדים

- לכל שאלה קובץ BAT משלה (`Q1_....bat`). דאבל-קליק: הלוח נצרב, השאלה מופיעה בחלון, מקלידים את התשובה שם. לא עורכים שום קובץ.
- **המספרים אישיים** - נבנים ממספר הסטודנט (נשמר ב-`student.txt` בתיקיית הקורס, אותו מספר לכל התרגילים).
- **תשובה שגויה = מספרים חדשים.** אין טעם לנחש - פותרים שוב מההתחלה.
- תשובה נכונה נותנת **קוד** בקובץ `moodle.txt` - אותו מגישים במודל. כל ניסיון נרשם ב-`results.txt`.
- `S` = לדלג על השאלה, `Q` = לעצור.
- SW0 הוא המתג הימני ביותר, HEX0 התצוגה הימנית ביותר.
