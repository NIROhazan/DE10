### Q01 - מעשרוני לבינארי

- **מתגים ונורות:** `the number = HEX1 HEX0 (decimal)     answer: SW6..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח מוצג מספר עשרוני, בשתי הספרות הימניות של התצוגה.
- האם הוא אי-זוגי? (מספר אי-זוגי = הביט הימני שלו 1)
- אי-זוגי - הרימו:
- `SW0`
- זוגי - השאירו למטה.

**שלב 2**

- שיטה 1: מה החזקה הגדולה ביותר של 2 שנכנסת במספר?
- `64 = SW6     32 = SW5     16 = SW4     8 = SW3`
- הרימו רק את המתג שלה.

**שלב 3**

- המספר כולו בבינארי: הורידו את החזקה, ומהשארית - שוב החזקה הגדולה שנכנסת, וכך הלאה.
- `64 = SW6   32 = SW5   16 = SW4   8 = SW3   4 = SW2   2 = SW1   1 = SW0`
- הרימו את המתגים של כל החזקות שהשתמשתם בהן.

### Q07 - כמה ביטים צריך?

### Q08 - חזקות גדולות של 2

- **מתגים ונורות:** `N = HEX1 HEX0 (decimal)     answer: SW8..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח מספר. מעריכים את 2 בחזקת המספר הזה:
- `2^N = 2^(N - 10k) x 2^(10k)`
- `2^10 = kilo     2^20 = mega     2^30 = giga`
- איזו יחידה יוצאת?
- `kilo = SW0     mega = SW1     giga = SW1 + SW0`

**שלב 2**

- ומה המספר שמכפיל את היחידה? הרימו את המתג שלו:
- `2^(N - 10k)`
- `1 = SW0   2 = SW1   4 = SW2   8 = SW3   16 = SW4`
- `32 = SW5   64 = SW6   128 = SW7   256 = SW8`
