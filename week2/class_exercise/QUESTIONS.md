נוצר אוטומטית מ-`gen.py` - כל שאלה כפי שהיא מופיעה על המסך, בלי התשובות. מסודר לפי הנושאים של השיעור (`tools/lesson.txt`).

## נושא 1 - מערכות ספירה: בינארי, הקסדצימלי וכמה ביטים

30 דקות, 4 שאלות: Q01-Q04

### Q01 - מעשרוני לבינארי

- **מתגים ונורות:** `the number = HEX1 HEX0 (decimal)     answer: SW6..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח מוצג מספר עשרוני, בשתי הספרות הימניות של התצוגה.
- האם הוא אי-זוגי? (מספר אי-זוגי = הביט הימני שלו 1)
- אי-זוגי - הרימו:
- `SW0`
- זוגי - השאירו למטה.

**שלב 2**

- שיטה 1: מה החזקה הגדולה ביותר של 2 שנכנסת במספר?
- `64 = SW6     32 = SW5     16 = SW4     8 = SW3`
- הרימו רק את המתג שלה.

**שלב 3**

- המספר כולו בבינארי: הורידו את החזקה, ומהשארית - שוב החזקה הגדולה שנכנסת, וכך הלאה.
- `64 = SW6   32 = SW5   16 = SW4   8 = SW3   4 = SW2   2 = SW1   1 = SW0`
- הרימו את המתגים של כל החזקות שהשתמשתם בהן.

### Q02 - מהקסדצימלי לבינארי

- **מתגים ונורות:** `the number = HEX1 HEX0 (hex)     answer: SW7..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח מוצג מספר הקסדצימלי בשתי ספרות.
- כתבו בבינארי (4 ביטים) את הספרה הימנית:
- `HEX0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`
- `A = 10   B = 11   C = 12   D = 13   E = 14   F = 15`

**שלב 2**

- עכשיו את הספרה השמאלית, בבינארי:
- `HEX1`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`
- `A = 10   B = 11   C = 12   D = 13   E = 14   F = 15`

**שלב 3**

- כל המספר: שתי ספרות הקס = 8 ביטים (בייט). הספרה השמאלית על ארבעת המתגים העליונים:
- `HEX1 -> SW7 SW6 SW5 SW4      HEX0 -> SW3 SW2 SW1 SW0`

### Q03 - מבינארי לעשרוני

- **מתגים ונורות:** `the number = LEDG7..LEDG0 (LEDG0 = 1, LEDG1 = 2, LEDG2 = 4 ... LEDG7 = 128)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בנורות הירוקות מוצג מספר בינארי. חברו את הערכים של הנורות הדולקות.
- מה ספרת המאות של המספר העשרוני? (0, 1 או 2)
- `0 = all down     1 = SW0     2 = SW1`

**שלב 2**

- מה ספרת העשרות שלו?
- `0 = all down    1 = SW0    2 = SW1    3 = SW1+SW0    4 = SW2`
- `5 = SW2+SW0    6 = SW2+SW1    7 = SW2+SW1+SW0    8 = SW3    9 = SW3+SW0`

**שלב 3**

- ומה ספרת האחדות?
- `0 = all down    1 = SW0    2 = SW1    3 = SW1+SW0    4 = SW2`
- `5 = SW2+SW0    6 = SW2+SW1    7 = SW2+SW1+SW0    8 = SW3    9 = SW3+SW0`

### Q04 - כמה ביטים צריך?

- **מתגים ונורות:** `the number = HEX2 HEX1 HEX0 (decimal)     answer: SW3..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח מוצג מספר עשרוני בשלוש ספרות.
- כמה ביטים צריך כדי לכתוב אותו בבינארי?
- כמה ביטים מספיקים לכל גודל:
- `7 bits -> 127      8 bits -> 255      9 bits -> 511      10 bits -> 1023`
- שימו את מספר הביטים:
- `7 = SW2+SW1+SW0     8 = SW3     9 = SW3+SW0     10 = SW3+SW1`

**שלב 2**

- כמה ספרות הקס צריך? כל ספרת הקס היא 4 ביטים.
- `2 = SW1     3 = SW1 + SW0`

## נושא 2 - חיבור, מספרים עם סימן והרחבה

30 דקות, 6 שאלות: Q05-Q10

### Q05 - מחבר עם מספר מוסתר

- **מתגים ונורות:** `A = SW9 SW8 SW7 SW6 (HEX0)     sum = LEDG3..LEDG0     carry = LEDG4     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- הלוח מחבר לכניסה מספר מוסתר, ומראה את הסכום (4 ביטים) ואת הנשא.
- שימו את ארבעת מתגי הכניסה למטה:
- `SW9 SW8 SW7 SW6 = 0000`
- עכשיו הנורות מראות 0 ועוד המספר המוסתר - כלומר את המספר עצמו. העתיקו אותו:
- `SW3..SW0 = LEDG3..LEDG0`

**שלב 2**

- גלישה: כשהסכום גדול מ-15 הוא לא נכנס ב-4 ביטים, ונורת הנשא נדלקת:
- `LEDG4`
- מה הכניסה הקטנה ביותר שמדליקה אותה? שימו אותה:
- `SW3..SW0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`

**שלב 3**

- הרימו את ארבעת מתגי הכניסה:
- `SW9 SW8 SW7 SW6 = 1111`
- מה מראות ארבע נורות הסכום? העתיקו:
- `SW3..SW0 = LEDG3..LEDG0`

### Q06 - סימן וגודל

- **מתגים ונורות:** `the number = LEDG3..LEDG0 (LEDG3 = sign, LEDG2..LEDG0 = magnitude)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בנורות מספר בשיטת סימן וגודל (4 ביטים): הנורה השמאלית היא הסימן.
- האם הוא שלילי? (סימן 1 = שלילי) שלילי - הרימו:
- `SW0`
- חיובי - השאירו למטה.

**שלב 2**

- מה הגודל שלו (שלוש הנורות הימניות)? שימו אותו:
- `4 = SW2     2 = SW1     1 = SW0`

**שלב 3**

- כתבו את אותו מספר במשלים ל-2, ב-4 ביטים:
- חיובי - אותם ביטים. שלילי - כתבו את הגודל ב-4 ביטים, הפכו את כל הביטים והוסיפו 1.
- `SW3..SW0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`

### Q07 - משלים ל-2

- **מתגים ונורות:** `the number = LEDG3..LEDG0 (two's complement, 4 bits)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בנורות מספר במשלים ל-2 (4 ביטים). הנורה השמאלית 1 = שלילי.
- שלילי - הרימו:
- `SW0`
- חיובי - השאירו למטה.

**שלב 2**

- מה הערך המוחלט שלו?
- שלילי - הפכו את כל הביטים והוסיפו 1. חיובי - הוא כמו שהוא.
- `SW3..SW0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`

**שלב 3**

- הפכו את הסימן שלו (הפכו את כל הביטים והוסיפו 1), ב-4 ביטים:
- `SW3..SW0`

### Q08 - מספר שלילי בבינארי

- **מתגים ונורות:** `the number = HEX1 HEX0 (decimal, a minus on HEX1 if negative)     answer: SW7..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח מספר עשרוני עם סימן. כתבו אותו במשלים ל-2, ב-4 ביטים:
- שלילי: כתבו את הערך המוחלט, הפכו את כל הביטים והוסיפו 1.
- `SW3..SW0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`

**שלב 2**

- ועכשיו ב-8 ביטים: העתיקו את 4 הביטים, ומלאו את 4 העליונים בביט הסימן (הביט השמאלי):
- `SW7..SW0`

### Q09 - חיסור במשלים ל-2

- **מתגים ונורות:** `the exercise = HEX3 - HEX1     answer: SW3..SW0 (two's complement, 4 bits)`
- **שלבים:** 2

**שלב 1**

- בלוח תרגיל חיסור. חיסור = חיבור של המספר הנגדי.
- שלב 1: כתבו את המספר הנגדי למספר הימני (הפכו את כל הביטים והוסיפו 1), ב-4 ביטים:
- `SW3..SW0`
- `8 = SW3     4 = SW2     2 = SW1     1 = SW0`

**שלב 2**

- שלב 2: חברו את המספר השמאלי ואת התוצאה של שלב 1. שמרו רק 4 ביטים (הנשא נזרק):
- `SW3..SW0`

### Q10 - הרחבת סימן והרחבה באפסים

- **מתגים ונורות:** `the number = LEDG3..LEDG0 (4 bits)     answer: SW7..SW0`
- **שלבים:** 2

**שלב 1**

- בנורות מספר של 4 ביטים. הרחבת סימן ל-8 ביטים:
- העתיקו את 4 הביטים למתגים התחתונים, ומלאו את 4 העליונים בביט השמאלי (ביט הסימן):
- `SW7..SW0`

**שלב 2**

- הרחבה באפסים ל-8 ביטים: 4 הביטים למטה, ו-4 העליונים תמיד 0:
- `SW7..SW0`

## נושא 3 - שערים לוגיים וטרנזיסטורים

30 דקות, 3 שאלות: Q11-Q13

### Q11 - איזה שער מוסתר בלוח?

- **מתגים ונורות:** `A = SW9     B = SW8     Y = LEDG0 (green)     answer: SW3..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח שער של שתי כניסות. נסו את 4 המצבים ורשמו בכל אחד אם הנורה דולקת:
- `SW9 SW8:   down-down,   down-up,   up-down,   up-up`
- לכל מצב שהנורה דלקה - הרימו מתג:
- `1st -> SW0     2nd -> SW1     3rd -> SW2     4th -> SW3`

**שלב 2**

- איזה שער זה? הרימו את המתגים שלו:
- `AND = all down   OR = SW0   XOR = SW1   NAND = SW1+SW0   NOR = SW2   XNOR = SW2+SW0`

### Q12 - שער של שלוש כניסות

- **מתגים ונורות:** `A = SW9     B = SW8     C = SW7     Y = LEDG0 (green)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח שער של שלוש כניסות. חצי ראשון: החזיקו למטה:
- `SW9 = down`
- נסו 4 מצבים ורשמו אם הנורה דולקת:
- `SW8 SW7:   down-down,   down-up,   up-down,   up-up`
- לכל מצב שהנורה דלקה - הרימו מתג:
- `1st -> SW0     2nd -> SW1     3rd -> SW2     4th -> SW3`

**שלב 2**

- חצי שני: אותו דבר, אבל החזיקו למעלה:
- `SW9 = up`
- `SW8 SW7:   down-down,   down-up,   up-down,   up-up`
- לכל מצב שהנורה דלקה - הרימו מתג:
- `1st -> SW0     2nd -> SW1     3rd -> SW2     4th -> SW3`

**שלב 3**

- איזה שער זה? זוגיות: שער שנותן 1 כשמספר ה-1 בכניסות אי-זוגי.
- `AND3 = all down   OR3 = SW0   XOR3 (odd) = SW1   NAND3 = SW1+SW0   NOR3 = SW2   XNOR3 (even) = SW2+SW0`

### Q13 - שער מטרנזיסטורים

- **מתגים ונורות:** `A = SW9     B = SW8     C = SW7     Y = LEDG0 (green)     answer: SW3..SW0`
- **שלבים:** 4

**שלב 1**

- בלוח שער אחד. עברו על 8 המצבים וזהו אותו:
- `SW9 SW8 SW7:   000   001   010   011   100   101   110   111      (0 = down, 1 = up)`
- `(gates with 2 inputs use only A and B)`
- `NAND2 = all down   NOR2 = SW0   NAND3 = SW1   NOR3 = SW1+SW0   AND2 = SW2   OR2 = SW2+SW0`

**שלב 2**

- בשער הזה, הטרנזיסטורים מסוג
- `nMOS`
- (הרשת שמחוברת לאדמה) - בטור או במקביל?
- `NAND: nMOS in series     NOR: nMOS in parallel     AND, OR: like their first stage`
- בטור - הרימו:
- `SW0`
- במקביל - השאירו למטה.

**שלב 3**

- והטרנזיסטורים מסוג
- `pMOS`
- (הרשת שמחוברת למתח)? הם תמיד הפוכים לרשת התחתונה.
- בטור - הרימו:
- `SW0`
- במקביל - השאירו למטה.

**שלב 4**

- כמה טרנזיסטורים יש בשער כולו? לכל כניסה זוג אחד; לשער
- `AND / OR`
- מוסיפים עוד מהפך של שני טרנזיסטורים.
- `4 = SW2     6 = SW2 + SW1`
