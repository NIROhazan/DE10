### Q01 - חזקות של 2 מהשקף

- **מתגים ונורות:** `N = HEX0     answer: SW8..SW0`
- **שלבים:** 2

**שלב 1**

- טבלת החזקות של 2 מהשקף: 1, 2, 4, 8, 16 ... בתצוגה מספר:
- `N = HEX0`
- מה זה 2 בחזקת המספר הזה? הרימו את המתג שלו:
- `1 = SW0   2 = SW1   4 = SW2   8 = SW3   16 = SW4`
- `32 = SW5   64 = SW6   128 = SW7   256 = SW8`

**שלב 2**

- מה ספרת האחדות של 2 בחזקת המספר הזה, בעשרוני?
- `N = HEX0`
- `0 = all down    1 = SW0    2 = SW1    3 = SW1+SW0    4 = SW2`
- `5 = SW2+SW0    6 = SW2+SW1    7 = SW2+SW1+SW0    8 = SW3    9 = SW3+SW0`

### Q16 - חזקות גדולות של 2

- **מתגים ונורות:** `N = HEX1 HEX0 (decimal)     answer: SW8..SW0`
- **שלבים:** 2

**שלב 1**

- בלוח מספר. מעריכים את 2 בחזקת המספר הזה:
- `2^N = 2^(N - 10k) x 2^(10k)`
- `2^10 = kilo     2^20 = mega     2^30 = giga`
- איזו יחידה יוצאת?
- `kilo = SW0     mega = SW1     giga = SW1 + SW0`

**שלב 2**

- ומה המספר שמכפיל את היחידה? הרימו את המתג שלו:
- `2^(N - 10k)`
- `1 = SW0   2 = SW1   4 = SW2   8 = SW3   16 = SW4`
- `32 = SW5   64 = SW6   128 = SW7   256 = SW8`
