### Q01 - איזה שער מוסתר בלוח?

- **מתגים ונורות:** `A = SW9     B = SW8     Y = LEDG0 (green)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח מוסתר שער אחד. שתי כניסות, יציאה אחת - הנורה הירוקה.
- שימו את שני המתגים למטה:
- `SW9 = down   SW8 = down`
- האם הנורה הירוקה דולקת?
- דולקת - הרימו:
- `SW0`
- כבויה - השאירו הכל למטה.

**שלב 2**

- בלוח מוסתר שער אחד. שתי כניסות, יציאה אחת - הנורה הירוקה.
- נסו את 4 המצבים של שני המתגים, ורשמו בכל אחד אם הנורה דולקת:
- `SW9 SW8:   down-down,   down-up,   up-down,   up-up`
- לכל מצב שהנורה דלקה - הרימו מתג:
- `1st -> SW0     2nd -> SW1     3rd -> SW2     4th -> SW3`

**שלב 3**

- בלוח מוסתר שער אחד. שתי כניסות, יציאה אחת - הנורה הירוקה.
- איזה שער זה? השוו את מה שרשמתם לשערים:
- `AND = 1 only if both are 1      OR = 0 only if both are 0`
- `NAND = 0 only if both are 1     NOR = 1 only if both are 0`
- `XOR = 1 when they differ        XNOR = 1 when they are equal`
- הרימו את המתגים של השער:
- `AND = all down   OR = SW0   XOR = SW1   NAND = SW1+SW0   NOR = SW2   XNOR = SW2+SW0`
