# 1. SOP קנוני: סכום של מינטרמים, מינטרם אחד לכל שורה שבה Y=1
SOP = B'A' + BA' + BA

# 2. POS קנוני: מכפלה של מקסטרמים, מקסטרם אחד לכל שורה שבה Y=0
POS = (B + A')

# 3. הביטוי הקצר ביותר שאתם מצליחים למצוא ל-Y
MIN = B + A'

# ------------------------------------------------------------
#  שאלות - ענו במילים שלכם, משפט או שניים
# ------------------------------------------------------------

# ש1. כמה מינטרמים יש ב-SOP שלכם, ולמה בדיוק המספר הזה?
ת1 = three minterms, one per row with Y = 1

# ש2. במקסטרם של השורה A=1 B=0: איזה משתנה מופיע עם ' ואיזה בלי, ולמה?
ת2 = a maxterm must be 0 on its row; OR is 0 only when every literal is 0, so B (=1) is complemented, A (=0) is not

# ש3. כאן POS קצר יותר מ-SOP. מה בטבלה מנבא את זה עוד לפני שכותבים משהו?
ת3 = only one row has Y = 0 (vs three with Y = 1), so POS has one term and SOP three

# ש4. נבאו לפני שאתם מזיזים מתגים: A=1 B=0 - אילו נורות LEDR יידלקו?
ת4 = A=1 B=0 -> LEDR0, LEDR1, LEDR2 all off, LEDR9 off
