#     Y = ((B + CA)' + B'C')'      (ID 316009489)

#  כמו בהרצאה: De Morgan מבחוץ פנימה (קודם ה-' החיצוני), ו-Involution (A'' = A) בכל פעם שאפשר.
#
#  סימונים:  A'  = NOT A   (אפשר גם ~A)      (A+B)' = NOT של כל הסוגריים
#            AB  = A AND B  (אפשר גם A*B או A&B)
#            A+B = A OR B   (אפשר גם A|B)
#
#  שורות שמתחילות ב-# הן הערות. כתבו רק אחרי ה-=

# 1. Y אחרי De Morgan: אסור ' אחרי סוגריים - רק על משתנה בודד (A', B'...). עדיין לא חייב להיות SOP או POS.
DM = (B + CA)(B + C)

# 2. SOP מינימלי ("multiplying out"): סכום של מכפלות, הכי מעט איברים ובהם הכי מעט ליטרלים
SOP = B + CA

# 3. POS מינימלי ("factoring"): מכפלה של סכומים, הכי מעט סוגריים ובהם הכי מעט ליטרלים
POS = (B + C)(B + A)

# ש1. מה ההפך של מכפלה לפי De Morgan, ומה ההפך של סכום? כתבו את שתי הצורות (T12 ו-T12') עם B ו-C.
ת1 = (BC)' = B' + C' (T12) and (B + C)' = B'C' (T12')

# ש2. למה מתחילים מה-' החיצוני ולא מהפנימי? מה היה קורה בביטוי שלכם אם הייתם מתחילים מבפנים?
ת2 = the outer bar covers everything; from the inside the inner bar is undone again later (extra steps, lost bars)

# ש3. כדי לעבור מ-SOP ל-POS השתמשתם ב-T8': W + XZ = (W + X)(W + Z). מה היו W, X ו-Z אצלכם?
ת3 = W = A, X = B', Z = C:  A + B'C = (A + B')(A + C)

# ש4. נבאו לפני שאתם מזיזים מתגים: A=1 B=0 C=0 - מה יהיה LEDG0, ואילו נורות LEDR יידלקו?
ת4 = A=1 B=0 C=0 -> Y = 0: LEDG0 off, LEDR0-2 off, LEDR9 off
