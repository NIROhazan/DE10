# 1. SOP קנוני: סכום של מינטרמים, מינטרם אחד לכל שורה שבה Y=1
SOP = BCA' + BC'A' + B'CA' + B'CA + B'C'A

# 2. POS קנוני: מכפלה של מקסטרמים, מקסטרם אחד לכל שורה שבה Y=0
POS = (B'+C'+A')(B'+C+A')(B+C+A)

# 3. SOP מינימלי: הכי מעט איברים, ובהם הכי מעט ליטרלים
MSOP = B'A + BA' + CA'

# 4. POS מינימלי: הכי מעט סוגריים, ובהם הכי מעט ליטרלים
MPOS = (B'+A')(B+C+A)

# ------------------------------------------------------------
#  שאלות - ענו במילים שלכם, משפט או שניים

# ש1. ל-Y יש יותר מ-SOP מינימלי אחד. מצאו SOP מינימלי שני, שונה מזה שכתבתם, והסבירו למה שניהם נכונים.
ת1 = the other of the two covers above; both cover every 1, both 3 x 2 literals

# ש2. ספרו ליטרלים ב-MSOP וב-MPOS שלכם. איזה קטן יותר, ומה בטבלה רמז לזה מראש?
ת2 = MSOP 6 literals, MPOS 5; only three 0s (and 001/011 pair up) vs five 1s

# ש3. השורה A=0 B=1 C=1 מכוסה אצלכם ב-MSOP על ידי יותר מאיבר אחד? למה מותר שאיברים יחפפו?
ת3 = with the B'C' cover, yes: A'C' and B'C' both cover 000; overlap is fine because 1 + 1 = 1

# ש4. נבאו לפני שאתם מזיזים מתגים: A=0 B=0 C=0 - אילו נורות LEDR יידלקו?
ת4 = A=0 B=0 C=0 -> Y = 0, LEDR0-3 off, LEDR9 off
