# ============================================================
#  תרגיל 0 - השאלות ש-Q01.bat ... Q10.bat שואלים
#  (קובץ למרצה - הסטודנט לא עורך אותו)
# ============================================================
#
#  כל סטודנט מקבל מספרים משלו לפי תעודת הזהות - המשוואה ורמת הקושי זהות לכולם.
#  run.bat מגריל מצב מתגים לפי ה-ת"ז (ולכן תמיד יש תשובה על הלוח) עד שהתנאים מתקיימים:
#
#  Qn:  Y = <משוואה> | SW                   חלק 1 - הסטודנט מקבל מתגים ומקליד מה רואים ב-HEX3 HEX2 HEX1 HEX0
#  Qn:  Y = <משוואה> | HEX: Y ? ? A         חלק 2 - מקבל ספרות ומקליד מתגים. אות = הספרה מוצגת לו,
#                                            ? = מוסתרת. כל מצב מתגים שנותן את הספרות מתקבל.
#       | MAX: 4                             לכל היותר 4 מצבי מתגים נותנים את הספרות (שלא יהיה קל מדי)
#       | IF: <תנאי PowerShell על $A $B $C $Y>  למשל $C -eq 0 ;  Bits $A = כמה ביטים דולקים ב-A
#
#  + = OR, * = AND, ~ או ' = NOT, ^ = XOR, ביט אחרי ביט על 4 ביטים.
#  משוואה חדשה מקומפלת בפעם הראשונה (כ-10 שניות) ונשמרת ב-sof/.
# ============================================================

# 1 - קל מאוד: רק לקרוא את התצוגה. Y הוא פשוט A
Q1:  Y = A                | SW | IF: (Bits $A) -ge 2

# 2 - קל: OR, בלי ביטים משותפים - נראה כמו חיבור
Q2:  Y = A + B            | SW | IF: $C -eq 0 -and $A -ne 0 -and $B -ne 0 -and ($A -band $B) -eq 0

# 3 - קל-בינוני: AND ביט אחרי ביט (למשל 7 AND 6 = 6, לא 42)
Q3:  Y = A * B            | SW | IF: $C -eq 0 -and (Bits $A) -ge 2 -and (Bits $B) -ge 2 -and $Y -ne 0

# 4 - בינוני: בכיוון ההפוך - A מוסתר, צריך לחשב אותו מ-Y דרך NOT של 4 ביטים
Q4:  Y = ~A               | HEX: Y C B ? | IF: (Bits $A) -ge 2

# 5 - בינוני: XOR עם ביטים משותפים - חייבים לכתוב בבינארי
Q5:  Y = A ^ B            | SW | IF: $C -eq 0 -and (Bits $A) -ge 2 -and (Bits $B) -ge 2 -and ($A -band $B) -ne 0

# 6 - בינוני-קשה: סדר פעולות על שלושה משתנים; A באמת מכבה ביט של B ש-C לא מדליק
Q6:  Y = A'B + C          | SW | IF: $A -ne 0 -and $B -ne 0 -and $C -ne 0 -and ($A -band $B -band (-bnot $C)) -ne 0

# 7 - קשה: B מוסתר - מוצאים אותו מ-Y, A, C (חוק הפילוג: (A+B)(A+C) = A+BC)
Q7:  Y = (A + B)(A + C)   | HEX: Y C ? A | MAX: 2 | IF: $A -ne 0 -and ($A -band 7) -ne 7 -and ($Y -band 7) -ne ($A -band 7)

# 8 - קשה: לפתור משוואת XOR - A מוסתר, מחשבים אותו מ-Y, B, C
Q8:  Y = A ^ B ^ C        | HEX: Y C B ? | IF: $B -ne 0 -and $C -ne 0 -and $B -ne $C -and (Bits $A) -ge 2

# 9 - מומחה: C' מדליק תמיד את הביט העליון, ו-A לא משפיע על Y. פותרים ביט-ביט מה C חייב להיות
Q9:  Y = B + C'           | HEX: Y ? B A | MAX: 2

# 10 - מומחה: (A+B)(A'+C) הוא בורר (MUX) לכל ביט - איפה ש-A=1 נלקח הביט של C, איפה ש-A=0 של B
Q10: Y = (A + B)(A' + C)  | HEX: Y C ? A | MAX: 4 | IF: ($A -band 7) -ne 0 -and ($A -band 7) -ne 7
