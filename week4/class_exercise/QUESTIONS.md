### Q15 - תבנית של casez עם סימני שאלה

- **מתגים ונורות:** `a[3:0] = SW9..SW6     match = LEDG0     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- בלוח שורה אחת של
- `casez (a)`
- הנורה דולקת כשהקלט מתאים לתבנית של השורה. סימן שאלה = כל ערך מתאים.
- `a[3:0] = SW9 SW8 SW7 SW6`
- מצאו קלט אחד שמדליק את הנורה, והעתיקו אותו:
- `SW3..SW0 = SW9..SW6`

**שלב 2**

- אילו ביטים בתבנית הם סימן שאלה? (שינוי שלהם לא מכבה את הנורה) הרימו מתג לכל אחד:
- `a[3] -> SW3     a[2] -> SW2     a[1] -> SW1     a[0] -> SW0`

**שלב 3**

- כתבו את התבנית: כל ביט שהוא לא סימן שאלה - הערך שלו; סימן שאלה - למטה.
- `a[3] -> SW3     a[2] -> SW2     a[1] -> SW1     a[0] -> SW0`
