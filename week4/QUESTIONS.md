### Q01 - מפת קרנו מהשקופיות - שלושה משתנים

- **מתגים ונורות:** `A = SW9     B = SW8     C = SW7     Y = LEDR0` ; `the cell = HEX2 HEX1 HEX0 (A B C)     answer: SW5..SW0`
- **שלבים:** 3

**שלב 1**

- נתונה בלוח אחת ממפות קרנו של שלושה משתנים מהשקופיות (שקופיות 3, 4, 19).
- המפה מסודרת כמו בשקופיות האלה. העמודות לפי:
- `AB`
- והשורות לפי:
- `C`
- המתגים שמשנים את ערכי המשתנים:
- `A = SW9     B = SW8     C = SW7`
- הנורה האדומה מציגה את:
- `Y = LEDR0`
- מלאו קודם את השורה הראשונה של המפה. שימו:
- `C = 0  (SW7 = 0)`
- בדקו באילו עמודות נדלקת הנורה האדומה, והרימו את המתג של כל עמודה כזו:
- `A B`
- `00 -> SW3`
- `01 -> SW2`
- `11 -> SW1`
- `10 -> SW0`
- רמז: העמודות בסדר של מפת קרנו, לא בסדר הספירה.
- בין שתי עמודות שכנות משתנה רק משתנה אחד.

**שלב 2**

- עכשיו השורה השנייה של המפה. שימו:
- `C = 1  (SW7 = 1)`
- בדקו שוב באילו עמודות נדלקת הנורה האדומה, והרימו את המתג של כל עמודה כזו:
- `A B`
- `00 -> SW3`
- `01 -> SW2`
- `11 -> SW1`
- `10 -> SW0`

**שלב 3**

- סמנו בעיגולים את ה-1 במפת הקרנו שמילאתם במתגים, כמו בשקופית.
- בתצוגת ההקס שעל הלוח מוצג התא שאליו מתייחסים בשאלה:
- `HEX2 HEX1 HEX0 = A B C`
- כתבו את המכפלה של העיגול שמכסה את התא הזה, והרימו מתג לכל ליטרל שלה:
- `A = SW5     A' = SW4`
- `B = SW3     B' = SW2`
- `C = SW1     C' = SW0`
- גרש = משתנה עם קו מעליו (שער מהפך). משתנה שלא מופיע במכפלה: שני המתגים שלו למטה.
- רמז: במכפלה של עיגול נשארים רק המשתנים שיש להם אותו ערך בכל התאים של העיגול.

### Q02 - מפת קרנו של ארבעה משתנים מהשקופית

- **מתגים ונורות:** `A = SW9     B = SW8     C = SW7     D = SW6     Y = LEDR0` ; `the cell = HEX3 HEX2 HEX1 HEX0 (A B C D)     answer: SW3..SW0`
- **שלבים:** 3

**שלב 1**

- נתונה בלוח מפת קרנו של ארבעה משתנים מהשקופית (שקופית 8).
- בתצוגת ההקס שעל הלוח מוצג תא אחד שלה:
- `HEX3 HEX2 HEX1 HEX0 = A B C D`
- המתגים שמשנים את ערכי המשתנים:
- `A = SW9     B = SW8`
- `C = SW7     D = SW6`
- הנורה האדומה מציגה את:
- `Y = LEDR0`
- שימו את שני המתגים השמאליים כמו בתצוגה. כך בוחרים את השורה של התא:
- `SW9 SW8 = HEX3 HEX2  (A B)`
- בדקו באילו צירופים של שני המתגים שלידם נדלקת הנורה האדומה, והרימו את המתג של כל צירוף כזה:
- `C D = SW7 SW6`
- `00 -> SW3`
- `01 -> SW2`
- `11 -> SW1`
- `10 -> SW0`
- רמז: אלה ארבעת התאים של שורה אחת במפה, בסדר של מפת קרנו.

**שלב 2**

- סמנו בעיגולים את ה-1 במפת הקרנו, כמו בשקופית 8.
- בתצוגת ההקס שעל הלוח מוצג התא של 1 שאליו מתייחסים בשאלה:
- `HEX3 HEX2 HEX1 HEX0 = A B C D`
- מצאו את העיגול שמכסה אותו, וכתבו על דף את המכפלה שלו.
- הרימו מתג לכל ליטרל של המשתנים האלה:
- `A, B`
- `A = SW3     A' = SW2`
- `B = SW1     B' = SW0`
- גרש = משתנה עם קו מעליו (שער מהפך). משתנה שלא מופיע במכפלה: שני המתגים שלו למטה.

**שלב 3**

- עכשיו שאר המכפלה של אותו עיגול, של התא שבתצוגה:
- `HEX3 HEX2 HEX1 HEX0 = A B C D`
- הרימו מתג לכל ליטרל של המשתנים האלה:
- `C, D`
- `C = SW3     C' = SW2`
- `D = SW1     D' = SW0`
- גרש = משתנה עם קו מעליו (שער מהפך). משתנה שלא מופיע במכפלה: שני המתגים שלו למטה.
